Axis가 Camera Station의 심각도 9.9 취약점과 대응 버전을 공지했습니다

Axis는 공식 보안 권고문에서 시스템 침해로 이어질 수 있는 CVE-2026-13312를 공개했으며, CVSS 3.1 점수는 9.9점입니다. 영향 대상은 AXIS Camera Station Pro 6.17 미만과 AXIS Camera Station 5.59 SR 2 미만입니다. 수정 권고문은 Pro 6.17 패치가 제공되었으며, Camera Station 5.59 SR 2는 11월 중 제공할 계획이라고 구분해 안내합니다.

실무 영향 및 검토사항

자사 VMS의 입력값 검증과 낮은 권한 계정의 공격 가능성을 우선 점검해야 합니다. 고객 공지에서는 패치가 제공된 제품과 제공 예정인 제품을 명확히 구분하고, 업데이트 전 백업·호환성 검증 절차를 함께 안내하는 것이 중요합니다.

02 · 2026-11-10

Axis가 Secure Entry의 API 인증 우회 취약점 패치를 발표했습니다

Axis는 특정 API 엔드포인트로 전송한 WebSocket 요청을 통해 별도 API 엔드포인트에 인증 없이 접근할 수 있는 CVE-2026-63288을 공개했습니다. 취약점의 CVSS 3.1 점수는 8.3점이며, 권고문은 A1210·A1601·A1610·A1710·A1810의 관련 Secure Entry 소프트웨어를 영향 대상으로 명시합니다. 수정 버전은 Secure Entry 12.11.106.1입니다.

실무 영향 및 검토사항

출입통제 장치와 카메라의 웹 관리 기능에서 일반 HTTP 요청뿐 아니라 WebSocket 연결 및 연결 이후의 API 권한 검증까지 시험해야 합니다. 엔드포인트 간 인증 정책의 일관성과 중요 기능의 서버 측 권한 검사를 보안 회귀시험 항목에 포함하는 방안을 검토해야 합니다.

i-PRO가 인증서 관리 기능을 강화한 장비 설정 도구를 공개했습니다

i-PRO는 Configuration Tool 5.0.0.3을 출시하고 어안·돔·불릿·멀티센서·리모트헤드 카메라와 네트워크 비디오 디코더의 지원 대상을 추가했습니다. HTTPS 서버 인증서 두 개를 설치·설정·검증·삭제하는 기능과 인증서 만료 임박 알림 기능을 추가했습니다. 일부 해상도 및 레코더 관련 기능은 향후 펌웨어나 소프트웨어 버전을 전제로 하므로 현재 즉시 사용 가능한 기능과 구분해야 합니다.

실무 영향 및 검토사항

대규모 카메라 운영에서는 인증서 교체와 만료 관리의 편의성을 제품 경쟁력 평가 항목으로 반영할 필요가 있습니다. 자사 설정 도구에서도 복수 인증서 관리, 만료 사전 알림 및 장비별 기능 지원 조건 표시를 검토하고, 지원 도구 출시를 개별 카메라의 신규 출시로 해석하지 않도록 경쟁정보를 관리해야 합니다.

i-PRO는 엣지 생성형 AI를 실제 보안 운영에 활용하는 방법을 소개하는 웨비나 안내를 발표했습니다. 주요 의제는 자연어를 통한 실시간 탐지 설정 간소화, 엣지 AI를 활용한 중요 이벤트 대응 및 실시간 탐지와 사후 검색·조사의 상호 보완입니다. 해당 원문은 웨비나 안내이며, 신규 제품 출시나 정량적인 성능 검증 결과를 발표한 자료는 아닙니다.

실무 영향 및 검토사항

자사 AI 영상분석의 경쟁력 검증에서는 사후 검색 정확도뿐 아니라 자연어로 탐지 조건을 설정하는 데 걸리는 시간과 실시간 알림의 유효성을 함께 평가해야 합니다. 제품 기획 단계에서는 현장별 표현 차이, 오탐률, 추론 지연 및 지원 언어를 검증 항목으로 설정하는 방안을 검토해야 합니다.
